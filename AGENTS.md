This is a passion project made and maintained by Humans. This project does not allow contributions generated by large languages models (LLMs) and chatbots.

This ban of AI generated content applies to all parts of the projects, including, but not limited to, code, documentation, issues, and artworks.
This includes AI-assisted works such as generating code snippets or spell checking text.

AI tools can be used to answer questions and find information. However, we encourage contributors to avoid them in favor of asking other people like maintainers or reading the documentation.
